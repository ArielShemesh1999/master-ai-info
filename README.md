## About

A Hebrew RTL landing page for a 10-week practical AI mastery course. Single-file static site with 12 sections covering the syllabus, interactive 3D character previews, animated voice orbs, an AI-image gallery, a Figma-style sandbox, and a workflow visualizer. Spring 2026 cycle, opens May 3.

### Sections

| # | Section | What it shows |
| --- | --- | --- |
| 01 | About | Hero with live countdown to spring cycle launch |
| 02 | Products | 6 product-tile grid (recordings, community, projects, stack, alumni, certificate) |
| 03 | Syllabus | 10-week vertical timeline with weekly checkpoints |
| 04 | Voices | 6 animated voice orbs with mock player |
| 05 | Visuals | 5-card AI image gallery |
| 06 | 3D | 5 interactive GLB character models (drag to rotate) |
| 07 | Playground | Figma-style sandbox with draggable artboard |
| 08 | Agents | Live workflow card with traveling packets between nodes |
| 09 | Instructor | Bio and credit chips |
| 10 | Proof | Asymmetric testimonial grid |
| 11 | Pricing | 3-tier pricing |
| 12 | FAQ | Native details Q&A accordion |

## Accessibility

Built-in floating accessibility widget — text size, high contrast, reduced motion, underlined links, grayscale. Settings persist on the device.

## Tech Stack

Vanilla HTML 5 · CSS · JavaScript · model-viewer for 3D · Google Fonts (Heebo, Anton, Inter Tight, JetBrains Mono, Newsreader) · No framework, no build step.
